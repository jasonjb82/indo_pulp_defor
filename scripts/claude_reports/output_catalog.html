Output Catalog: Indonesia Pulp Deforestation Paper

This document maps every figure, table, and empirical statistic in the paper and SI to the script that generates it, along with the full upstream dependency chain. It is intended as the definitive reference for building a reproducible pipeline.

Last reviewed: 2026-05-19
Repository layout at time of review: - scripts/01_data_extraction/ — GEE JavaScript - scripts/02_data_preparation/ — data cleaning and intermediate table construction (Jason’s scope) - scripts/03_analysis_modelling/ — statistical models and scenario analysis (Robert’s scope) - scripts/04_figures_and_outputs/ — figures and paper statistics (Robert’s scope) - scripts/99_archive/ — retired scripts (some still produce needed files — see §6)

Issue 2 — Broken source() paths for color palettes

01_summary_figure.R, 02_deforestation_timing.R, and 03_land_use_change.R all source:

source("scripts\\001_misc\\001_color_palettes.R")

The file has moved to scripts/04_figures_and_outputs/001_color_palettes.R. These source paths are broken.

Issue 3 — Statistics printed to console but not saved

The following scripts produce paper-critical outputs that exist only in the R session: - 12_paper_stats.R — ~35 inline statistics - 22_pulp_expansion_scenarios.R — 7 scenario statistics + expansion_gt table - 21_pulp_expansion_model.R — ROC-AUC, PR-AUC, Brier score, confusion matrix - 23_rs_accuracy_assessment.R — all accuracy metrics for SI Tables 4–5

Issue 4 — Hardcoded scalar values in 12_paper_stats.R

Mill capacity expansion values are hardcoded (lines 416–420) rather than derived from data: - oki_exp_mt = 4.2 (OKI mill expansion, million tonnes/year) - rapp_exp_mt = 1.33 (RAPP expansion) - rappbctmp_exp_mt = 1.3 (RAPP BTMP) - phoenix_exp_mt = 1.7 (Phoenix Resources)

Similarly, new_wood_demand = 34.27 in 22_pulp_expansion_scenarios.R is hardcoded and should be derived from the capacity data in 12_paper_stats.R.

# Output Catalog: Indonesia Pulp Deforestation Paper

This document maps every figure, table, and empirical statistic in the paper and SI to the script that generates it, along with the full upstream dependency chain. It is intended as the definitive reference for building a reproducible pipeline.

**Last reviewed:** 2026-05-19  
**Repository layout at time of review:**
- `scripts/01_data_extraction/` — GEE JavaScript
- `scripts/02_data_preparation/` — data cleaning and intermediate table construction (Jason's scope)
- `scripts/03_analysis_modelling/` — statistical models and scenario analysis (Robert's scope)
- `scripts/04_figures_and_outputs/` — figures and paper statistics (Robert's scope)
- `scripts/99_archive/` — retired scripts (some still produce needed files — see §6)
